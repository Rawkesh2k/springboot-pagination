## 🌟 About

A student records management web application that demonstrates server-rendered pages and pagination. The student table displays each record's roll number, name, and email, while pagination controls help navigate the records.

## ✨ Features

- 🎓 Display student roll number, name, and email
- 📑 Paginate student records for easier navigation
- 🎨 Responsive, styled interface using HTML and CSS
- 🖥️ Server-side rendering with JSP and JSTL
- 🗄️ MySQL database with sample records for testing

## 🧰 Technology

| Area | Technologies |

| Database | MySQL |

## 🚀 Setup and usage

### 1. 📥 Get the project

```bash
git clone https://github.com/Rawkesh2k/springboot-pagination.git
cd springboot-pagination
```

### 2. 🗄️ Set up the database

Run the SQL script provided in the repository to create and populate the `pages_for_students` table. Configure the application with the appropriate MySQL connection settings for your environment.

### 3. ▶️ Deploy and run

Deploy the JSP-based application to a compatible server, such as Apache Tomcat. Follow the project configuration and server instructions for the correct deployment steps.

### 4. 📄 Browse records

Open the deployed application in your browser and use the pagination controls to navigate between student record pages.
